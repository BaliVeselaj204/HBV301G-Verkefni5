# Verkefni 5 — Gæðakröfur, árekstrar og viðskiptareglur (HBV301G)

## Kerfi og höfundar

- **Heiti kerfis:** Sjálfvirkt bílastæðakerfi.
- **Hópmeðlimir:** Hópur 5: Bali Nói Veselaj og Kristinn Freyr Óskarsson.

### Um kerfið

Sjálfvirkt bílastæðakerfi er ætlað ökumönnum og rekstraraðilum gjaldskyldra bílastæða. Kerfinu er ætlað að skrá komu og brottför ökutækja, reikna stæðisgjald samkvæmt gjaldskrá viðkomandi svæðis og senda greiðslubeiðni að lokinni dvöl. Markmiðið er að draga úr fyrirhöfn ökumanna og minnka handvirka vinnu við eftirlit og innheimtu.

## Forsendur og kerfismörk

- Bílastæðakerfið heldur utan um dvöl ökutækja, reiknar gjald og sendir greiðslubeiðnir til ytra greiðslukerfis sem annast innheimtuna.
- Hver dvöl hefur einstakt auðkenni. Ný heimsókn sama ökutækis telst önnur dvöl.
- Gjöld og tímasetningar í samþykktarprófunum eru prófgögn. Forsendur um mínútugjald, afslætti og lágmarksgjald eru tilgreindar við prófin og lýsa ekki staðfestri gjaldskrá rekstraraðila.
